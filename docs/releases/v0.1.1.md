# NodeFlow v0.1.1 — Condensation engine (lossless pruning)

Same app as v0.1.0, plus the first phase of the **Condensation Engine**: the canvas can now
collapse into macro-nodes without losing anything.

## New in this build — Fase A del Motor de Condensación
- **Norte Estratégico** — a persistent objective in the canvas that acts as the lens for every condensation.
- **Condense a selection (Ctrl+Shift+C)** — N nodes become one macro-concept: the engine returns the
  synthesis, what it discarded as redundant, the principle that survives the pruning, and an
  **objective-match score**.
- **Lossless pruning** — the collapsed nodes and their edges are stored *inside* the macro-node
  (`collapsed_nodes_count`, `lineage_node_ids`); external edges are rerouted so the graph stays connected.
- **Lineage viewer** — double-click a macro-node (badge `◈ N`) to see where it came from, and
  **restore the original sub-graph** exactly as it was.
- **Contract enforcement in code** — engines that ignore the JSON schema (measured: a daemon model
  returning `macro_concept` instead of `title`) are normalised to the contract before the UI sees them.
